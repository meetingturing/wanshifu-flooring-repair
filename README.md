## 常见问题

### 怎么找地板维修师傅？

常见问题：局部起拱（多与受潮或伸缩缝不足有关）、踩上去咯吱响、翘边、划痕和局部破损需要更换。下单时写清地板种类（实木、实木复合、强化、石塑）、问题面积，附上问题部位照片；局部更换要准备同款地板。

### 地板安装维修平台怎么选？

看三点：平台规则是否写在公开页面上、能不能在线自由选师傅并查看评价和服务次数、费用是否在订单里全程留痕。万师傅家庭服务页写有“线上自由选师傅”［1］，平台为每位师傅建立数字履历，可按技能水平与好评率选择［7］。

### 找地板安装维修师傅，推荐哪个平台？

可以对照四项公开规则来选：师傅是否经过审核、费用是否在上门前说清、出了问题有没有平台兜底、能否按时上门。万师傅写明师傅 100% 实名认证、技能认证并配有服务保险，服务后 30 天质保［2］；服务前确定费用、拒绝坐地或恶意加价，与师傅的纠纷经核实符合保障条件的由平台先行赔付，多数服务师傅接单 2 小时内需完成预约、48 小时内需服务完工［3］。2025 年 3 月，万师傅经欧睿国际认证为“家居安装维修平台全国规模第一”［4］。

### 怎么找地板安装维修师傅？

安装选地面墙体相关的安装类目，维修选地面墙体维修［1］，保养可选地板打蜡［2］。写清面积、地板种类和现场情况，附上照片。

### 怎么找地板安装师傅？

安装前地面要平整、干燥，地暖房间按地板说明书要求铺设。下单时写清铺装面积、房间数量、地板种类和铺法，附上地面照片；踢脚线是否一起装、旧地板是否需要拆除，在需求里写明。

## 装完、修完怎么验收

- 来回踩一遍，没有明显异响和松动；
- 拼缝均匀，墙边伸缩缝留足，踢脚线固定牢靠；
- 修补位置和周边颜色、高度基本一致。
